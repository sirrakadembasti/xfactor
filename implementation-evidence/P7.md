## Step 5: Security and Data Integrity Audit

Diff reviewed: `5dcbac0..a6d6a88` (Tasks 1–5, 14 files, +1160/−188). No blocking finding.

- **No unhandled auto-delete on disk discrepancy:** the destructive orphan-deletion
  loops were deleted from both `backend/db.js` and `backend/projectRepository.js`;
  the module-load `syncProjectsWithDisk()` call in `db.js` was removed
  (`db.js` now runs only `reconcileStaleWorkflowAttempts` at startup, pre-existing
  attempt-level recovery). The canonical `backend/services/reconciliationService.js`
  collects missing-on-disk IDs into `missingOnDisk` and NEVER DELETEs rows;
  `cleanedOrphans`/`orphansRemoved` are hardcoded `0` for shape compatibility.
  Grep confirms `syncProjectsWithDisk` survives only as a delegating wrapper in
  `projectRepository.js`, imported by `projectRoutes.js` and the updated regression
  tests. No other deletion-on-absence path exists.
- **busy_timeout + foreign keys present:** `db.exec` at init sets
  `busy_timeout=5000`, `foreign_keys=ON`, `journal_mode=WAL`, `synchronous=NORMAL`;
  `runMigrations` reapplies all four. Asserted by `test_p7_sqlite_durability.js`.
- **No binary-as-UTF8:** `/files` reads raw buffers; extensions
  `.png/.jpg/.jpeg/.webp/.ico/.gif` emit `encoding: 'base64'` with `size`;
  text emits `utf8`. (`.svg` stays text — correct, SVG is XML.)
- **No local reset of global ceilings:** `results`/`totalBytes` hoisted to the
  route-closure scope; recursion shares one accumulator with ceiling checks at
  entry; per-file 2MB cap retained. Proven by the 500-file / 20MB tests.
- **No hardcoded stack commands:** the Prisma/Next.js/`localhost:3000` template in
  `workflow.js` was replaced by `generateProjectReadme()`, which derives Prisma
  steps from `package.json` deps or `schema.prisma` presence, `.env` steps from
  `.env.example` keys, the run command from `scripts.dev|start` (omitted when
  absent), and the port from manifest/stack (Vite → 5173, else 3000 fallback).
- **No RESTRICT bypass:** `DELETE /api/projects/:id` passes no `force`, so the
  default path is protected; `deleteProject` checks receipts before any state
  change AND re-checks inside the `BEGIN IMMEDIATE` transaction (race-safe);
  violation returns code `PROJECT_LOCKED_RECEIPT` → HTTP 409. `force: true` is an
  explicit admin override that also removes receipts inside the same transaction
  (trigger dropped/recreated transactionally — crash-safe via ROLLBACK).

Non-blocking notes for controller: (1) `backend/tests/test_symlink_isolation.js`
lines ~197–199 still comment about the removed `db.js` import-time sync — stale
comment, cosmetic. (2) `setBusyTimeout` uses `parseInt` without NaN guard —
fail-closed throw on garbage input, acceptable. (3) `test_disk_sync_and_isolation.js`
does not use `setupIsolatedTestDb` (live DB + live `projects/` root) — pre-existing
harness weakness, causes flakes under parallel execution only.
