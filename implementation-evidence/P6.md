## Step 5: Security and Operability Audit

Audit findings against blocking conditions:
- **No install fallbacks:** Root `Dockerfile` and `.github/workflows/ci.yml` strictly use `npm ci` with no fallback.
- **Single image:** `backend/Dockerfile` and `frontend/Dockerfile` deleted; only root `Dockerfile` exists.
- **Frontend node_modules isolated:** Backend and test modules import `jszip` directly from backend resolution; no `frontend/node_modules` fallback exists.
- **Non-root runtime:** `USER xfactor` enforced in container runtime; durable storage `/app/backend/data` and `/app/projects` are properly owned.
- **SPA fallback bounds:** `isSpaNavigation` excludes `/api`, `/ws`, `/healthz`, `/readyz`, and files with extensions.
- **Cache headers:** `index.html` receives `no-cache`; fingerprinted assets receive `public, max-age=31536000, immutable`.
- **Durable roots:** Declared volumes for `/app/backend/data` and `/app/projects`.
- **Network security:** TLS terminated by reverse proxy; loopback trust validated by `TRUST_PROXY=loopback`.
- **P5 integrity:** Capability-proven sandbox execution, canonical artifact identity, and MFA session gating preserved.
