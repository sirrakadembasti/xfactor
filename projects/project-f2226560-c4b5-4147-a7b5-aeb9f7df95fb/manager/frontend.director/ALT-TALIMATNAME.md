# Frontend Domain Alt-Talimatnamesi (Next.js & Tailwind CSS)

## 1. Mimari ve Teknoloji Standartları
- **Framework:** Next.js (App Router, React 19 / 18, TypeScript)
- **Stil & Tasarım:** Tailwind CSS, `clsx`, `tailwind-merge`
- **İkonlar:** `lucide-react`
- **Form Yönetimi & Validasyon:** `react-hook-form`, `@hookform/resolvers`, `zod`
- **Bildirimler:** `sonner` (Toast bildirimleri)
- **API İletişimi:** Fetch API / Axios tabanlı istemci modülü (`@/lib/api.ts`)
