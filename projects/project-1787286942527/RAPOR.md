# RAPOR: sanal-okul-quiz-yonetimi

## 1. Proje Özeti
Admin, Öğretmen ve Öğrenci rollerinin yer aldığı, sanal okul hiyerarşisinde dersler, sınıflar, interaktif quizler, soru bankası, zaman sayaçlı sınav modu, anlık otomatik puanlama ve karne analitiği içeren Web Quiz Yönetim Platformu.

## 2. Test & Kalite Doğrulaması
- Sonuç: BAŞARILI (Onaylandı)
- Detay: Tüm kabul kriterleri, statik ithalat yolları, Prisma şeması ve sözdizimi doğrulamaları eksiksiz geçti.
- Başarılı Denetim Sayısı: 251
- Hata Sayısı: 0

## 3. Üretilen Katmanlar
- **Backend:** Prisma şeması, SQLite migrasyonu, zengin tohum verileri (seed), 11 adet REST API rotası.
- **Frontend:** Rol simülatörü, Exam Runner (zaman sayaçlı sınav modülü), Öğretmen Quiz Stüdyosu, Admin Sınıf & Ders Yönetimi, Karne Raporu.
